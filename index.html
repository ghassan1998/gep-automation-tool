CAPABILITIES

Equation parser

Paste a GeneXproTools function directly into the app. No file conversion, no manual retyping of terms.

Live Excel formulas

Every prediction and every R² cell is a real formula, not a frozen number. Edit the data and the workbook recalculates on its own.

Fit analysis

Predicted vs. experimental plotted automatically, with R², RMSE, MAE, and MAPE computed alongside it.

Sensitivity study

Sweep each input variable one at a time and see exactly how the model responds, variable by variable.

Report export

A live-formula Excel workbook and a PDF report, ready to hand to a reviewer or a supervisor.

No dependencies

Runs as a standalone Windows installer. No Python, no separate libraries to set up.

HOW IT WORKS

  1. 01

    Paste the equation

    Drop in your GeneXproTools Python function as-is.

  2. 02

    Upload the data

    Bring in your dataset as an Excel or CSV file.

  3. 03

    Map the variables

    Match each column to the equation's input, and pick the experimental target.

  4. 04

    Review the fit & sensitivity

    See R², error metrics, and a one-at-a-time sensitivity sweep for every variable.

  5. 05

    Export the report

    Get a live-formula Excel workbook and a PDF summary in one click.
